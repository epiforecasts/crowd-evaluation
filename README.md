# crowd-evaluation

> **Archived.** No longer maintained; last updated November 2021. It holds only rendered HTML; the code that produced the reports is not in this repository.

Rendered weekly reports for the epiforecasts COVID-19 crowd forecasts of European countries, published as a website between April and November 2021. Every commit is an automated update adding that week's reports.

- `index.html`: landing page, "Covid-19 Crowd Forecast Ensemble and Evaluation Reports".
- `reports/ensemble-report-<date>.html`: weekly reports on the crowd forecast ensemble.
- `reports/evaluation-report-<date>-<country>.html`: weekly evaluation reports for each European country and overall.
- `reports/uk-challenge/`: the evaluation page for the UK COVID-19 Crowd Forecasting Challenge (see also `epiforecasts/uk-challenge`).
